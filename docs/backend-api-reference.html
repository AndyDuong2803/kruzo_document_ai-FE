Kruzo OCR API Reference

Frontend hiện chỉ dùng một backend endpoint: template-based OCR extraction. Endpoint standard OCR cũ đã bị loại khỏi source vì response không ổn định và không phục vụ workflow thật của user.

Public endpoint https://api.smartocr.kruzo.tech/api/v1/ocr/extract-custom
Runtime config NEXT_PUBLIC_API_BASE_URL
Current auth No API key required for beta endpoint

Nguồn source: src/features/ocr/api/*, src/features/ocr/preview/*, src/components/demo/*, src/components/docs/*.

POST /api/v1/ocr/extract-custom

Template-based OCR extraction

Đang được /try gọi Đang được /try/api gọi multipart/form-data
MethodPOST
Path/api/v1/ocr/extract-custom
Full URLhttps://api.smartocr.kruzo.tech/api/v1/ocr/extract-custom
Content typemultipart/form-data
AuthFrontend hiện không gửi Authorization header.

Request parameters

TênBắt buộcKiểuHợp lệLỗi/cần xử lý
file Yes Binary file part PDF, JPG/JPEG, PNG, WEBP. Unsupported: WAR_OCR_BIZ_2002. Empty: WAR_OCR_BIZ_2003. Too large: WAR_OCR_BIZ_2001.
schema_sample Yes JSON schema string JSON object có type, properties, field string hoặc table array. Invalid JSON: ERR_OCR_BIZ_2000. Too large: WAR_OCR_BIZ_2004.

Request example

curl -X POST "https://api.smartocr.kruzo.tech/api/v1/ocr/extract-custom" \
  -F "file=@repair-order.pdf" \
  -F 'schema_sample={"type":"object","properties":{"customer_name":{"type":"string"},"total_amount":{"type":"string"}}}'

Success response

{
  "success": true,
  "error_code": null,
  "message": "Data extracted successfully.",
  "data": {
    "fields": {
      "customer_name": {
        "value": "Maria Nguyen",
        "confidence": 0.96,
        "review_required": false
      }
    },
    "tables": [
      {
        "name": "line_items",
        "rows": [
          { "item": "Oil change", "qty": 1, "amount": "89.00" }
        ]
      }
    ],
    "review": {
      "status": "needs_review",
      "reason": "Some fields have lower confidence."
    }
  }
}
Frontend templates that create schema_sample
TemplateFieldsTables
Invoicevendor_name, customer_name, invoice_number, invoice_date, total_amountline_items: item, qty, amount
Certificate / Diplomafull_name, institution_name, certificate_name, major_or_program, issue_dateKhông có mặc định
Customer formcustomer_name, phone_number, email, address, request_summaryKhông có mặc định
Repair ordercustomer_name, repair_order_number, service_date, asset_or_vehicle, total_amountservice_items: service, qty, amount
Custom fieldsUser tự thêm field. Frontend yêu cầu có ít nhất 1 field hoặc table column trước khi submit.Optional custom table, mặc định tên Items.
Response contract frontend supports
ShapeFrontend xử lý
{ success, error_code, message, data }Contract chính. UI hiển thị message và normalize data.
data.fields objectMỗi key thành field. Value có thể là primitive hoặc object có value, confidence, review_required.
data.fields arrayĐọc label từ field, name, key, hoặc label.
data.tablesĐọc rows, data, hoặc items; frontend có thể tự suy ra columns.
confidence, score, confidence_levelĐổi thành High/Medium/Needs review.
review_required, needs_reviewĐổi thành Approved hoặc Needs review.
